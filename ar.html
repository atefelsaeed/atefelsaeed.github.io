RepoSphere

الفكرة
لوحة واحدة للمطورين اللي شغالين على ريبوهات كتير وعلى أكتر من منصة. الريبوهات والـ commits والـ pull requests والـ issues والإصدارات والإشعارات من GitHub وGitLab في مكان واحد، بدل التنقل بين التابات والحسابات.
دوري
بنيته لوحدي ومفتوح المصدر، من مواصفات المنتج ونظام التصميم لحد الكود. Flutter للويب أولًا، وبنفس الكود على Android وiOS وmacOS وWindows وLinux.
القرارات التقنية
Clean Architecture بطبقات domain وdata وpresentation، وRiverpod لإدارة الحالة، وGoRouter للتنقل. كل منصة ليها data source خاص بيها ورا repository واحد، فإضافة GitLab متطلبتش أي تعديل في الشاشات. تسجيل الدخول لـ GitHub بـ OAuth Device Flow، والتوكنز في تخزين آمن، ولو التوكن انتهى في أي مكان بيعمل تسجيل خروج من خلال observer واحد للتطبيق كله.
الجودة
GitHub Actions بيشغّل التحليل والاختبارات وبناء نسخة الويب مع كل push، وSentry لتتبع الأعطال. والشغل متقسم سبرنتات وموثّق في الريبو.
الجاي
دعم أكتر من حساب، علشان تربط كذا حساب GitHub وGitLab، مثلًا حساب لكل عميل.
